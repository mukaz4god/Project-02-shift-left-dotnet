# DefectDojo Integration

## Objective

Centralize security findings from SAST, SCA, container scanning, DAST, and secrets scanning.

## Findings Sources

- Semgrep
- Gitleaks
- CodeQL
- Dependency-Check
- Trivy
- OWASP ZAP

## Lifecycle

1. Import findings
2. Triage
3. Assign severity
4. Track remediation
5. Retest
6. Close

## Environment

DefectDojo is currently deployed locally for portfolio/lab usage.
